# Roadmap

## Q2 2025

- [ ] **QUIC Support**: Full implementation of IETF QUIC.
- [ ] **Zero-Copy**: Enhance `io_uring` support for zero-copy sends.
- [ ] **Rust Bindings**: Native Rust crate for the core library.

## Known Limitations

- Windows support is currently experimental.
- `io_uring` requires kernel 5.19+.
