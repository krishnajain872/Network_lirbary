# Pros & Cons

## Pros

- **Extreme Performance**: Outperforms Nginx and Envoy in raw throughput benchmarks.
- **Flexibility**: Protocol-agnostic design allows easy switching.
- **Modern C++**: Uses C++20 coroutines for clean async code.

## Cons

- **Maturity**: Newer project, less battle-tested than Nginx.
- **Ecosystem**: Fewer plugins available compared to established proxies.
- **Complexity**: Requires C++ knowledge for deep customization.
