# Configuration

NetworkLib supports a robust configuration system using YAML files. It allows hot-reloading of certain parameters (like TLS certificates and rate limits) without restarting the server.

## Basic Structure

```yaml
server:
  name: "MyServer"
  version: "1.0.0"
  mode: "tcp" # options: tcp, http, grpc, websocket, udp

network:
  port: 8080
  host: "0.0.0.0"
  backlog: 1024

performance:
  event_loop_type: "epoll" # or "io_uring"
  worker_threads: 4
  buffer_size: 4096

ssl:
  enabled: true
  cert_file: "/etc/certs/server.crt"
  key_file: "/etc/certs/server.key"

resilience:
  rate_limiter:
    per_ip_enabled: true
    per_ip_requests_per_second: 1000
```

## Hot Reloading

The `ConfigHotReload` class watches the configuration file for changes. When a change is detected, it automatically updates:

1.  **TLS Context**: Reloads certificates if the paths change.
2.  **DDoS Protection**: Updates rate limits dynamically.

> **Note:** Changing the port or event loop type requires a server restart.
